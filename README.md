# 📌 Customer Support Chatbot

A responsive and interactive Customer Support Chatbot developed using HTML, CSS, and JavaScript.

This chatbot helps users get instant support for customer queries such as order tracking, refunds, shipping, payments, account issues, and product support through an easy-to-use chat interface.

---

## 🚀 Features

* 💬 Real-time chatbot interaction
* 📦 Order tracking support
* 💰 Refund and return assistance
* 🚚 Shipping information
* 💳 Payment issue handling
* 📱 Responsive user interface
* ⚡ Automated FAQ responses
* 🧠 Keyword-based query detection

---

## 📖 How It Works

1. User enters a message in the chatbot.
2. The chatbot analyzes the query using keyword matching.
3. An automated response is generated instantly.
4. Users can also access support using category tabs.
